# Примеры вопросов для MARS

| Область | Вопрос |
|---|---|
| Наука | Какие механизмы связывают микробиом кишечника с депрессией и насколько силён причинный вывод? |
| Технологии | Сможет ли натрий-ионная технология вытеснить LFP в стационарных накопителях к 2030 году? |
| Бизнес | Какова реальная экономика вертикальных ферм и почему многие из них обанкротились в 2023–2025? |
| Междисциплинарный | Как повышение температуры влияет на производительность труда и ВВП в странах с жарким климатом? |
| Политика | Что говорит доказательная база об эффективности безусловного базового дохода? |

Запуск: `mars run "<вопрос>"` (или `--mock` для демо).
