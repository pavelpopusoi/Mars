Multi-Agent Research System · v0.3

MARS: команда агентов, которая проводит исследование за вас

На вход сложный вопрос из науки, техники, бизнеса или на стыке областей. На выход отчёт с источниками, разобранными противоречиями, проверяемыми гипотезами, графом знаний и полной записью шагов.

Как идёт исследование

  1. PlannerРазбивает вопрос на 3–6 подвопросов и поисковые запросы
  2. Searcher × N и ReaderПараллельно ищут в вебе и читают ваши PDF и файлы, извлекают утверждения
  3. AnalystСинтезирует знания, оценивает силу доказательств
  4. CriticИщет противоречия и пробелы, при необходимости запускает новый раунд поиска
  5. HypothesisПредлагает гипотезы с методом проверки и условием опровержения
  6. WriterПишет отчёт со ссылками на источники, код добавляет граф и таблицы
graph LR
  Q[Вопрос] --> P[Planner]
  P --> S1[Searcher q1] & S2[Searcher qN]
  D[/Ваши файлы/] --> RD[Reader]
  S1 & S2 & RD --> A[Analyst]
  A --> C{Critic}
  C -- пробелы --> S4[Searcher: доисследование]
  S4 --> A
  C -- достаточно --> H[Hypothesis]
  H --> G[(Граф знаний)]
  G --> W[Writer]
  W --> R[/report.md/]

Цикл критики ограничен параметром max_rounds (по умолчанию 2), поэтому стоимость запуска предсказуема.

Агенты и их контракты

Агенты обмениваются только валидируемыми Pydantic-схемами, модель отвечает через structured outputs.

АгентДелаетВыходEffort
PlannerДекомпозиция, запросы, критерии успехаResearchPlanhigh
Searcherweb_search + web_fetch, затем извлечение Source/Claim только по найденным URLSearchFindingsmedium
ReaderЧитает ваши PDF, TXT, MD, CSV, JSON как источникиSearchFindingsmedium
AnalystКлючевые выводы, консенсус, открытые вопросыSynthesishigh
CriticПротиворечия с причиной и разрешением, слабые утверждения, пробелыCritiquehigh
HypothesisНовые фальсифицируемые гипотезыHypothesisSethigh
WriterТекст отчёта со ссылками [id]ReportDraftmedium

ФайлСодержимое

Запуск

pip install -e ".[dev]"

# демо без ключа
mars run "Вопрос" --mock

# реальный запуск со своими файлами
export ANTHROPIC_API_KEY=sk-ant-...
mars run "Вопрос" --doc report.pdf --max-cost 10

mars estimate   # оценка стоимости
mars serve      # веб-интерфейс

Решения

  • Оркестратор в коде: порядок шагов и стоимость предсказуемы
  • Утверждения как триплеты: граф строится без лишних вызовов модели
  • Упавший подвопрос пропускается, а не роняет весь запуск
  • Серверные фолбэки, если модель откажется отвечать
  • MockLLM: тесты и CI без сети и затрат
  • Оценка стоимости до запуска и лимит --max-cost
